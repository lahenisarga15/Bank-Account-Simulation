Bank Account Simulation
A beginner-friendly Java project developed as part of the Elevate Labs Java Developer Internship — Task 5.

Features

- Deposit money
- Withdraw money
- Check account balance
- Maintain transaction history
- Validate invalid amounts and insufficient funds

Technologies

- Java
- Object-Oriented Programming (OOP)
- ArrayList

Project Files

- "Main.java" — Runs the simulation
- "Account.java" — Manages balance and transactions
- "Transaction.java" — Stores transaction details

How to Run

Compile the Java files:

javac Main.java Account.java Transaction.java

Run the program:

java Main

Learning Outcome

Practiced classes, objects, encapsulation, methods, constructors, and basic collection handling.
